#+TITLE: Obsidian Cycle 63 — Whole-command selected-object undo
#+DATE: 2026-10-13
#+STARTUP: overview

* Delivered vertical slice

With F8 enabled, =Ctrl+Alt+Z= undoes the newest active original command group
touching the selected SDF object. Newer edits to unrelated objects remain.
The normal =Ctrl+Z= chronological history and =Ctrl+Shift+Z= redo keep their
existing meanings. Multi-object command groups are indivisible.

The same engine-owner journal operation is exposed through the compiled
Monad host binding =sdf-inspect-undo-selected!= and the public C agent API
=obs_agent_scene_undo_selected=. Each entry point uses existing owner and
mutation/effect admission.

* Implementation

- =src/scene/sdf_inspector.[ch]= selects the latest active original group by
  scene ticket, preflights every group member, and reuses the existing
  inverse-record publisher. Conflicts do not partially change scene state.
- Chronological undo skips original groups deactivated by selected-object
  undo. The undo count omits inactive original groups.
- =src/platform/input.c= adds F8-scoped =Ctrl+Alt+Z=, guarded against modal
  editor ownership, viewport drags and active property gestures.
- The Monad host and external C agent route into the same journal; no mutable
  scene pointers or second history are added to the public API.
- The new native fixture compiles production inspector, SDF ticket and GPU
  frame-slot publication sources together.

* Remaining acceptance

On a configured workstation, edit multiple objects, use =Ctrl+Alt+Z= on an
older object's edit, continue with chronological undo, and verify grouped
conflict refusal, explicit redo, Vulkan validation and compiled Monad
behavior. The journal is bounded and volatile; this feature does not
implement mesh/topology deletion undo or Emacs text-region selective undo.
