* Architectural result

A production-connected, cancellable multi-object SDF inspector gesture:
- real renderer-backed preview, separated from committed Emacs-like undo;
- explicit =begin= / =end= / =abort= exposed to external C and compiled Monad;
- cancellation and commit preflight entire final live state before mutation;
- accepted group becomes one Emacs-like undo unit, even across scene objects;
- abort preserves previous committed history, including prior redo inverses;
- 64-preview cap refuses overflow *before* publication and never truncates an
  active speculative edit; no-op previews are free;
- full-group oldest-history eviction (no partial multi-edit command);
- retained scene epoch, stale tickets and owner/effect admission constraints.

See =docs/SCENE-GESTURES.org= and the GNU Emacs Lisp manual Atomic Changes.
The real =modules/obsidian/sculpture.mon= demonstrates a language-created,
cancelled live tint before its committed on-frame tint/undo/redo flow.
The external C integration fixture independently submits a production Vulkan
frame *during the preview*, then demonstrates cancel, accept and undo
against the same scene. The final capture is another distinct frame.
