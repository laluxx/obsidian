* Scope

Incremental patch from canonical Cycle 3 =obsidian/= to Cycle 4.

Patch includes only modified and added files, NOT a complete engine tree.

* Engineering work delivered

- =src/monad/hotreload.[ch]=: monotonic owner-thread stable file watcher,
  optional =OBSIDIAN_MONAD_WATCH=1=, checked file snapshots, bounded
  reload/retry scheduling, native pointer reacquisition.
- =src/graphics/msdf_generator.{h,cpp}= + =tools/msdf/= build an
  optional C++ generator backed by upstream Chlumsky/msdfgen. Input:
  Unicode glyph in a TTF/OTF font. Output: linear RGB MSDF in RGBA8,
  image dimensions, projection and pixel-range metadata.
- =shaders/msdf_glyph.frag= is a separate GPU decoding reference; not
  wired into the existing bitmap-font 2D pipeline. 3D scene SDF unchanged.
- Source organization =/// SectionName= in Obsidian C/headers/tests/GLSL.
  No vendor source has been reformatted.
- Updated =README.md=, one central =TODO.org=, source-specific
  =docs/{HOTRELOAD,MSDF}.org=, and Monad-language policy test fixtures.

* Integration and quality gates NOT claimed

- Not compiled against the real MonadC SDK, Vulkan, GL shader compiler,
  FreeType, Jolt or the real msdfgen CMake targets here.
- No Vulkan runtime, end-to-end glyph atlas, GPU shader sampling, or visual
  quality tests; do not treat this as shipped UI font replacement.
- No atomic transactional native-image hot swap. Existing MonadC loader
  may modify live runtime state during unsuccessful loads. Requires compiler
  candidate image, prepare/commit/abort API and quiescent reclamation.
- Monad-language tests are fixtures but not executed without MonadC.
