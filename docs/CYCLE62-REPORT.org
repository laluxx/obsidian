#+TITLE: Obsidian Cycle 62 — Durable appearance presets
#+DATE: 2026-10-13
#+STARTUP: overview

* Delivered slice

Cycle 61 added an in-memory SDF appearance clipboard. Cycle 62 persists that
value-only clipboard as a portable OBSLOOK v1 preset and provides an
independent Python authoring path:

F8 SDF tool → Ctrl+Shift+C copy → Ctrl+Shift+S save → new run or external
authoring → Ctrl+Shift+L load → Ctrl+Shift+V paste onto a sphere, box or
terrain → one undoable scene edit → existing per-frame SDF buffer publication.

Loading changes only clipboard state. It does not mutate a scene object or
create undo history. Applying the sample uses the existing material/emission
property bridge, preserving target geometry, transform, CSG properties and
terrain octaves.

* Changed production systems

- =src/editor/sdf_appearance_clipboard.[ch]= implements an explicit 100-byte
  format, endian-independent packing, IEEE binary64 checks, version/size
  validation, CRC32/IEEE, numeric validation, and fail-closed load semantics.
- =src/platform/input.c= adds F8-scoped Ctrl+Shift+S/L save/load operations;
  Ctrl+Shift+C/V remain in-memory copy/paste. The path is
  =OBSIDIAN_SDF_LOOK_PATH= or =./obsidian-appearance.obslook=.
- =src/core/atomic_file.c= is reused; no second atomic writer is introduced.
- =tools/obslook.py= independently writes and inspects the format using only
  Python's standard library.
- Native C and Python tests exercise both codec directions and production
  clipboard/scene-journal behavior.
