#+TITLE: Obsidian Monad migration — Cycle 1 delivery
#+DATE: 2026-10-10
#+STARTUP: overview

* Scope completed in source

1. All 31 pre-existing first-party C translation units, with accompanying
   headers, moved out of the root/editor split into an owned =src/=
   subsystem layout.  Core graphics algorithms remain unchanged.
2. =Makefile= now discovers subsystem translation units and produces .d
   dependency files; installed flat header surface is retained for now.
3. Persistent engine Monad runtime added at =src/monad/runtime.[ch]=.
4. Host capabilities registered at =src/monad/bindings.[ch]=, including
   generation-checked scene/camera foreign references and dynamic key
   procedure dispatch with owner-thread and recursion guards.
5. Compiled native Monad policy named =obsidian_camera_step_mm : Int -> Int=
   loaded from a module via the same ABI as Glemax's tested Monad host and
   hooked to =C-M-<right>= when =OBSIDIAN_MONAD_BOOT= is configured.
6. Optional F5 module reload added as a DEVELOPMENT pathway, not guaranteed
   atomic hot replacement; failures disable the potentially stale native
   callable.
7. One central =TODO.org= with the original hand-written task notes saved
   verbatim at =docs/archive/original-TODO.org=.
8. New Monad source examples/tests only; no new C test code introduced.

* No claim of completion

engine or a finished REPL.  The legacy graphics/audio/physics implementations
remain the behavior reference and fallback.
