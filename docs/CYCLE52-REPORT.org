* Vertical slice delivered

Cycle 51 already proved at the C-source seam that Monad and the external
agent share stable scene-epoch sphere tickets. Cycle 52 makes that shared
identity useful: a Monad frame raycasts a live sphere, selects it, tints it,
undoes and redoes the tint. After five steps, the external agent inspects the
same selected sphere and history, edits RGBA/PBR, undoes, verifies original
color, redoes and captures the production Vulkan frame. No new GPU buffers,
interpreter, duplicated scene or shadow model were introduced.

* Ownership and correctness

** DONE Shared fixed-storage editor core
- =src/scene/sdf_inspector.[ch]= keeps 64 pre/post commands and one selection,
  all keyed by the same nonreused scene ticket namespace as Cycle 51.
- Values are float-quantized *before* publication, so repeated replay does
  not accumulate double/float conversion drift. History reserves storage
  statically: selection, edit, undo and redo do not allocate.
- No-op edits do not consume history. Editing after undo truncates the redo
  tail; when full the oldest command is evicted. Undo or redo verifies the
  current object's entire supported PBR/position/radius snapshot and refuses
  with a distinct conflict result if legacy/Monad code has changed it.
- A scene lifetime-epoch transition invalidates selection and journal. A
  stale or geometrically incompatible ticket fails closed. Direct legacy
  writes bypass the journal by design and may cause a safe conflict.
- Real edits use the existing CPU =scene.sdfs= and =flushSdfSSBO= with Cycle
  50's deferred Vulkan flight-slot publication. No device-wide stall added.

** DONE One checked language and outer agent editing surface
- Outer =obsidian_agent.h= adds select, edit (field mask), selected, undo,
  redo, history counts and explicit discard-history; no Vulkan/MonadC types
  enter the public C ABI. Wrong-thread, recursive-call and mutating-effect
  policy remain enforced.
- =src/monad/sculpt_api.c= registers eight actual host callbacks; all mutating
  operations check engine-thread and GPU effect admission. Read-only status
  queries do not request GPU mutation privileges.
- Only translation-only primitive spheres are supported. Radius changes,
  mesh editing, physics rollback, serialized history and camera screen-pick
  remain out of scope; this is not presented as an entire GUI inspector.

* Strict runtime acceptance, not claimed as passed

#+begin_src sh
make -j2 test
make test-sculpture-runtime
# outputs: build/tests/sculpture.{rgba,json,png}
#+end_src

The strict test verifies that scene construction happens in the compiled
Monad frame callback, the selection/history persists into the external C
client, undo/redo preserves the correct material, and a nonuniform RGBA
capture is returned by the real Vulkan frame. The latter is a heuristic, NOT
a pixel-level golden image or a QTT proof. The SDK needed to build and run
that linked test is not installed in the test container.
